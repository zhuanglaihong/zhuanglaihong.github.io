## 关于这个站点

主页用 **Scene Deck** 范式组织内容:

- **Scene 1 · 核心简历** — 居中头像 + 4 个 tab 切换(基本与技能 / 教育与实习 / 研究项目 / 发表论文)
- **Scene 2 · 个人空间** — 太阳系平面 3D 星图(中心 hub + 6 个轨道节点),点击节点平滑滚动到对应模块详情(兴趣爱好 / 读书见闻 / 博客 / 旅行摄影 / 我的资源 / 联系我)

支持开场动画(可跳过)、Canvas 背景、Lightbox 看图、博客文章详情页、键盘 / 鼠标 / 触屏多种导航。

## 技术栈

- 纯 **HTML / CSS / JavaScript** — 没有构建工具,没有 npm 依赖
- 内容由 [`data.js`](./data.js) 一个文件驱动
- [GitHub Pages](https://pages.github.com/) 静态托管
- 设计灵感来自 [Brittany Chiang](https://brittanychiang.com/) 的暗色配色,Scene Deck 范式参考了一个产品发布动画的设计感觉
