## 关于这个站点

主页采用“**个人介绍与作品 + 个人空间**”两层结构:

- **Scene 1 · 个人主页** — 展示个人背景、九个项目与作品、论文和经历；项目支持主题筛选及详情阅读
- **Scene 2 · 个人空间** — 连续滚动展示兴趣爱好、读书见闻、技术随笔、旅行摄影、资源收藏和私人电台，顶部模块卡可快速跳转

支持开场加载动画、Canvas 背景、Lightbox 看图、博客文章详情页、键盘 / 鼠标 / 触屏多种导航。加载结束后进入个人主页。

## 技术栈

- 纯 **HTML / CSS / JavaScript** — 没有构建工具,没有 npm 依赖
- 内容由 [`data.js`](./data.js) 一个文件驱动
- [GitHub Pages](https://pages.github.com/) 静态托管
- 设计灵感来自 [Brittany Chiang](https://brittanychiang.com/) 的暗色配色,Scene Deck 范式参考了一个产品发布动画的设计感觉
